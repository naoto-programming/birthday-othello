# 誕生日オセロ v5 設計仕様(角のマス)

作成日: 2026-11-18
前の仕様: `docs/superpowers/specs/2026-11-16-birthday-othello-v4-opening-design.md`(書いていない点は v4 → v3 → v2 → v1 のまま)

## 1. 目的

ユーザーの要望: 「角のマスは角から1マス以内のどこかに駒が置かれないと置けないようにして」。

オセロと同じく、角の石は挟まれず裏返らない。空いている角に早いうちから自由に置けると、取ったもの勝ちになりやすい。角に置けるのは、その周りで戦いが始まってからにする。

## 2. ルール

- 角のマス(今の盤面の四隅)は、その角に隣り合う3マス(縦・横・斜め)のどれかに石があるときだけ置ける。石の色は問わない。この3マスがすべて空いている角を「閉じた角」と呼ぶ。
- 盤面が広がったあと(12×12・14×14)は、広がった盤面の四隅が角になる。(コントローラーの判断)
  - 12×12 に広がった直後の角は閉じている(隣の3マスは、新しく増えた空きマス)。
  - 14×14 に広がった直後の角は、最初から開いている。盤面は埋まったときにだけ広がるので、新しい角の斜め隣にある 12×12 の角には必ず石があるため。(2026-11-18 の最終レビューで、当初の「広がった直後の新しい角は閉じている」という書き方が 14×14 では成り立たないと分かり、規則どおりの動きに合わせて直した)
- 閉じた角は、v4 の「置けないマス」と同じ扱いにする。
  - 序盤の3ターンの制限と合わせて、置けないマスが空きマスのすべてになったときは、その手に限りどこにでも置ける(v4 の例外のまま)。
  - 様子見の代償の判断にも使う(閉じた角では挟めないので、実際には影響しない)。
- 最初の石(v4)は、角ごとに次の5マスには置かない: 角、角のとなり3マス(上下左右と斜め)、角から斜めに2つ目のマス(8×8 では (2,2)・(2,5)・(5,2)・(5,5))。開始時の四隅は、いつもすべて閉じている。
  - 2026-11-19 のユーザーの要望(2回):
    - 1回目「最初の石は四角から2マス以上離れた部分に置く」で、角のとなり3マスを除いた。それまでは角だけを除いていたため、1000通りの配置のうち643通りで、最初の石が角のとなりにあり、その角が1手目から開いていた。
    - 2回目「角に隣り合わせまたは1つとなりの斜めにスタート時の駒は置かれないようにして」。どの形かを図で確かめ、ユーザーが「斜めの2つ目も除く」を選んだ。
  - 置ける候補は44マス。石1個で除かれるマスは最大9なので、4個目のときも候補は17マス以上残り、必ず4個置ける。
- 効果の「植える」も、閉じた角は選べない。(コントローラーの判断)「奪う」「固定」「鬼は外」は石のあるマスが対象なので関係しない。
- ほかのルールは v4 のまま。

## 3. 画面

- 閉じた角には、v4 の置けないマスと同じ斜線の印を付ける(序盤だけでなく、対戦中ずっと)。
- 閉じた角をタップしたら、置かずに注意を出す: 「角は、となりに石が置かれるまで置けません」。
  - 序盤(v4 の予約行がある間)は、その行に出す(v4 と同じ)。
  - 序盤のあとは、手番の文の行をその注意に差し替える(目立つ色)。次の描画で元に戻る。行が増えないので盤面は動かない。(コントローラーの判断)
- 自分の石の周り(序盤)のマスをタップしたときの注意は v4 のまま。
- ルール画面に1項目足す: 「角のマスは、となりの3マスのどれかに石が置かれるまで置けません(盤が広がったあとの角も同じ)。」
- ルール画面の最初の石の項目を「最初に黒白2個ずつの石が、ランダムな場所に置かれます(角、角のとなり、角から斜めに2つ目には置かれません)。」に変える(2026-11-19)。

## 4. テストとバランス

- 単体テスト:
  - 閉じた角は置けず、隣の3マスのどれかに石があれば置ける
  - 12×12 の角も同じ
  - 最初の石は角・角のとなり3マス・角から斜めに2つ目に来ず、それ以外の44マスはどれも使われる。開始時の四隅はすべて閉じている
  - 植えるは閉じた角を選べない
  - 閉じた角しか空いていない…という状況は起きない(角の隣が空いていれば、その隣のマスが空いている)ので、例外のテストは v4 のものを使う
- 既存の単体テストで、離れたマスとして空の角(例: (7,7))に打っているものは、角でない離れたマスに変える。テストの意図は変えない。
- スモークテスト:
  - 空の盤面(`?opening=off`)で四隅に印があること
  - 角をタップしても置かれず、手番の文が注意に変わること
  - 隣に置いたあとは印が消えて置けること
  - 序盤(`?seed=`)の印が「自分の石の周り」と「閉じた角」の和になること
  - 序盤(`?seed=`)の開始時は、四隅すべてが閉じた角で、角から斜めに2つ目のマスに石がないこと
- バランス確認は v4 と同じ条件で OK になること。先手の勝率も見る(参考値)。
