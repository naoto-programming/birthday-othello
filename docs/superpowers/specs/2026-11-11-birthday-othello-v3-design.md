# 誕生日オセロ v3 設計仕様

作成日: 2026-11-11
前の仕様: `docs/superpowers/specs/2026-11-07-birthday-othello-v2-design.md`(この文書に書いていない点は v2、さらに書いていない点は v1 のまま)

## 1. 目的

v2 を遊んだうえでの要望に応える。

- 置く前の確認(予告 → 決定)をやめて、タップしたらすぐ置く。
- 盤面が全部埋まったらサドンデスにする。マスが広がって新しく置ける場所ができ、先に自分の誕生日の日付を通過した人が勝つ。

## 2. ルールの変更

### 2.1 置き方と裏返し

- 空きマスをタップすると、すぐにその人の石を置く。予告と決定の手順はなくす。
- 挟んだ列はすべて裏返す。v2 の「返す列を選べる」はなくす。
- 日数調整の効果があり、かつ1枚以上返す手では、タップの後に −3〜+3 を選んでから日付を動かす。
- 石を選ぶ効果(鬼は外・固定・奪う・植える)は、候補のマスを1回タップすると確定する(v1 と同じ)。v2 の改善版で入れた「選択 → 決定」はなくす。
- 様子見の代償、イベント、石の重さ、移動の計算順は v2 のまま。

### 2.2 段階とサドンデス

ゲームには3つの段階がある。

| 段階 | 盤面 | 誕生日での勝ち方 | 移動 |
|---|---|---|---|
| 0(通常) | 8×8 | ぴったり止まったら勝ち(通り越したら跳ね返る) | v2 のまま |
| 1(サドンデス) | 12×12 | 届くか通り越したら勝ち(跳ね返らない) | v2 のまま |
| 2(サドンデス×2) | 14×14 | 届くか通り越したら勝ち(跳ね返らない) | 1手の移動マス数を2倍(様子見の代償も2倍) |

- 段階0で盤面が埋まったら、段階1に進む。盤面の周りに2周のマスが増えて12×12になる。
- 段階1で盤面が埋まったら、段階2に進む。周りに1周増えて14×14になる。
- 段階2で盤面が埋まったら、v2 の「盤面が埋まったときの判定」で決める(残りマス数 → 石の数 → 引き分け)。
- 盤面が広がるとき:
  - 置かれていた石は、色・重さ・固定のまま、広がった盤面の中央の同じ見た目の位置に移る。
  - 日付の位置、予定されている効果、使用済みのイベントはそのまま。
  - 手番は、盤面を埋めた手の次の人(もう一手なら同じ人)。
- 段階1・2では、日付が誰かの誕生日に届くか通り越したら、その誕生日の人の勝ち(誰が動かしても)。日付の位置は範囲の端(0 または N)で止める。
- 段階2の2倍は、移動の計算(2倍・+3・調整・おやすみ・うそ、または様子見の代償)の最後に掛ける。
- イベントは、日付が動いて範囲内のイベントのマスに止まったときに発動する(v2 のまま)。誕生日の勝ちが優先。

## 3. 画面の変更

- 盤面の大きさは段階に合わせて8・12・14マス四方で描く。各マスの日付は、今の月の1日から順に、マスの数(64・144・196日)だけ印刷する。マスが小さくなるので、日付と石の数字の文字も小さくする。スマートフォン(幅390px)の14×14で1マス約25px。
- 打つ流れ:
  - タップで置く。
  - 日数調整があるときだけ、盤面の下に −3〜+3 のボタンと「別のマスにする」を出す。ボタンには結果も表示する(例: 「+2(3マス → 11/8)」)。押すと置いて日付が動く。
- 予告パネル、半透明の石、返す列の枠、行き先の点滅はなくす。
- サドンデスに入るとき(段階1)はポップアップを出す: 「盤面が埋まった! サドンデス: マスが広がり、先に自分の誕生日を通り越した人の勝ち」。
- 段階2に入るときもポップアップを出す: 「さらに広がり、日付の動きが2倍に」。
- 上部の帯に「サドンデス」(段階2は「サドンデス ×2」)の札を出す。
- 結果の理由:
  - 段階1・2で誕生日に届いた・通り越したとき: 「サドンデスで、日付が◯/◯(◯◯の誕生日)を通り越しました」。ぴったりの場合は「…に届きました」でもよい。
  - 段階2で盤面が埋まったとき: 「サドンデスでも盤面が埋まりました」と、v2 と同じ残りマスの説明。
- ルール画面: 予告・列の選択の説明を消し、すぐ置くこと、全部返ること、サドンデスと2倍の説明を足す。

## 4. アニメーション

- 今の演出は残す:
  - 石が落ちる
  - 近い順に返る
  - 日付の移動(ページめくりは1手で最大2回)
  - 跳ね返り(段階0のみ)
  - 光る名札と効果
  - ポップアップ
  - ろうそく
  - 花火
- 盤面が広がるとき:
  - 中央の石が少し縮んで中央に寄る。
  - 新しい外周のマスがふわっと現れる(約0.6秒)。
- サドンデスの札は、現れたときに1回脈打つ。
- 端末の「動きを減らす」設定では、これらの動きをなくす。
- v2 改善版で入れた演出の修正を引き継ぐ:
  - 手番の表示と石の数字は、演出の後に切り替える。
  - 裏返る石の数字は、打つ前の本当の重さで見せる(重さリセットのイベントで0にならないように)。
  - 勝った手の演出中に「対戦終了」を先に出さない。

## 5. テストとバランス

- 単体テスト:
  - 盤面の広げ方(石の位置・重さ・固定)
  - 12・14マスでの挟み判定
  - 段階の進み方と、段階2が埋まったときの判定
  - 段階1・2の通過勝ち(誰が動かしても、跳ね返らない)
  - 段階2の2倍(様子見の代償も含む)
  - 全部の列を返すこと
  - 裏返る前の重さの記録
- スモークテスト:
  - タップですぐ置くこと
  - 日数調整のパネル
  - 自動で打ち続けて盤面が埋まると、サドンデスのポップアップ・144マス・札が出ること
  - 最後まで打てること
  - これまでの中断や動きを減らす設定の確認は残す
- バランス確認(`npm run balance`)では、ていねいなAI同士の結果を次の4つの終わり方の割合で表示する:
  - 段階0のぴったり
  - 段階1
  - 段階2
  - 最後の判定

  最後の判定で決まった割合が10%以下で、すべての対局が終わっていれば合格。

## 6. 対象外

v2 と同じ(コンピューター対戦、通信対戦、待った、途中保存、効果音、家族の誕生日の登録)。
